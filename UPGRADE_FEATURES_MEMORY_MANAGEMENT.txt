FEATURE 1: AUTOMATIC MEMORY CLEANUP (SAFE)
================================================================================

Description:
  Runs Python garbage collection periodically to free unused memory

Impact on Trading Logic: ZERO
  - Just frees memory that Python is holding but not using
  - Doesn't change any trading decisions
  - Doesn't affect data
  - Runs in background, non-blocking

Implementation:
  import gc
  import time

  def memory_cleanup_task():
      """Run garbage collection periodically"""
      while True:
          try:
              # Force garbage collection
              gc.collect()
              
              # Clear Python internal caches
              gc.collect(generation=0)
              gc.collect(generation=1)
              gc.collect(generation=2)
              
              logger.info("Memory cleanup completed")
          except Exception as e:
              logger.error(f"Memory cleanup error: {e}")
          
          # Run every 5 minutes
          time.sleep(300)

  # Start in background thread
  cleanup_thread = threading.Thread(target=memory_cleanup_task, daemon=True)
  cleanup_thread.start()

Benefits:
  - Frees 50-200 MB of unused memory
  - Zero impact on trading
  - Prevents memory leaks
  - Safe for live trading

Recommendation: IMPLEMENT - Safe and beneficial

              memory = psutil.virtual_memory().percent
              
              if memory > 85:
                  # Aggressive throttling
                  self._llm_cooldown_seconds = 120  # 2 minutes
                  logger.warning(f"High memory ({memory:.1f}%) - LLM throttled to 120s")

                  logger.info(f"Moderate memory ({memory:.1f}%) - LLM throttled to 60s")
